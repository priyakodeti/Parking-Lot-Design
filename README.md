# Parking Lot System

A Low Level Design (LLD) implementation of a Parking Lot System using Java.

## Features

* Supports multiple floors
* Different types of parking slots
* Supports different vehicle types
* Assigns suitable parking slots to vehicles
* Vehicle entry and exit management
* Displays available parking slots on each floor
* Object-oriented design using separate classes

## Classes

* `ParkingLot` - Manages the overall parking lot
* `ParkingFloor` - Manages parking slots on a floor
* `ParkingSpot` - Represents an individual parking slot
* `Vehicle` - Represents a vehicle
* `VehicleType` - Represents different vehicle types
* `Car` - Represents a car
* `Bike` - Represents a bike
* `ParkingLotSystem` - Contains the main method and demonstrates the system

## Technologies
